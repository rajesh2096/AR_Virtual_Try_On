# AI Virtual Dress Try-On - Flutter Mobile App

Cross-platform (Android & iOS) mobile application for virtual dress try-on.

## Features
- User Registration & JWT Authentication
- Garment catalog / Wardrobe management
- Camera capture & Gallery image selection
- Try-on session creation and history tracking
- Dynamic Backend URL configuration for Android Emulator (`10.0.2.2`), iOS Simulator (`127.0.0.1`), and physical devices.

## Running the App
```bash
flutter pub get
flutter run
```
